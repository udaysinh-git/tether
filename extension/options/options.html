Tether settings

Connection

Agent sessions

Let agents ask to start a session

Keeps a local connection to Tether so an agent can ask to open its own window or to use the tab you're on. It sees nothing until you allow it.

Ask before an agent opens its own window

Turn this off to let agents open a separate window without a prompt. Your other tabs stay private either way.

Real input

Use the debugger for clicks, typing and network capture

Sites see clicks and keys exactly as if you made them, page scripts run past strict security policies, and the network log includes response bodies. The browser shows a “started debugging this browser” bar while a tab is shared.

Recording

Record what you type

Passwords, card numbers, one-time codes and similar fields are always masked. Turn this off to record only that a field was filled.

Recordings are saved in ~/.tether/sites, one folder per site. Delete a folder to forget a site.

Gallery

Scripts are ordinary userscripts in ~/.tether/scripts and styles are UserCSS in ~/.tether/styles. Download one to install it in Tampermonkey, Violentmonkey or Stylus, or publish it as a secret Gist to share the link.
